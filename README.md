# 轻记 · 电子错题本

这是作者根据自己的情况做的适配手机、平板的极简版错题本，没错，是极简版。我们删除了大部分的装饰模块，仅保留了最原始展示题型功能，这样才能让用户知道你弄的是错题本（九转大肠乱入）

快到期末考试了，希望大家取得自己满意的成绩。

## 功能

- 从相册选图或使用支持的手机浏览器拍照，每条记录保存 1–6 张图片。
- 添加、编辑、查看和删除错题，点击图片可放大查看。
- 新增分类，在录入或编辑时选填分类，并按分类筛选。没有错题的分类也会保留。
- 自动将图片压缩为 JPEG，最长边 2400 像素；支持浏览器“添加到主屏幕”。
- 错题记录和分类保存在 D1，图片保存在 R2，服务端按登录用户隔离数据。

## 本地运行

需要 Node.js 22.13 或更新版本。完整下载并解压本仓库后，在项目根目录执行：

```sh
npm ci
npm run build
```

随后按 [BUILDING.md](BUILDING.md) 初始化**全新的本地数据库**，再启动：

```sh
npm run dev -- --hostname 127.0.0.1
```

打开 <http://127.0.0.1:5173/>，页面会进入本地模拟登录流程。本地数据与作者的线上数据分开，不需要作者账号或 API 密钥。

本项目包含服务端、数据库和图片存储，不能通过双击 HTML 或仅上传到 GitHub Pages 运行。手机长期使用需要部署自己的 HTTPS 实例，参见 [部署与身份配置](DEPLOYMENT.md)。
